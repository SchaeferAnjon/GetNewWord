FAQ

常见问题

支持哪些语言？

AI 认得的文字都行：英语、德语、法语、西语、日语等。译文默认是中文，设置里可以换成别的语言。

查词会打断我看视频吗？

不会。查词面板不抢键盘，空格照样暂停、播放视频；点面板外面它就消失，想留着可以钉住。

不联网能用吗？

查词要用 AI，需要联网。词库和 Anki 卡片都在你电脑上，断网也能看。

怎么收费？

填自己的 API Key 永久免费，费用按服务商的价格从你自己的账户扣。会员给不想配 Key 的人，用我们的 AI：前 100 位新用户免费 30 次，之后每月 ¥9.9 或每年 ¥99（美元是 $1.99 或 $19.9），每天最多 200 次。人民币也可以用微信一次买 1 个月或 1 年，不自动续费。

怎么管理订阅、取消？

在应用的设置里打开 AI 服务 页，点 管理会员，再点 管理订阅：在 Stripe 的页面里换卡、改月付年付或取消，取消后用到这一期结束。没装应用或换了电脑，用这个登录链接，填付款时的邮箱，Stripe 会发一封登录信。微信一次买的到期就停，不会自动扣款。

怎么连 Anki？

开着 Anki 桌面版就行。GetNewWord 在设置 › Anki 里一键装好免费插件 AnkiConnect，之后自己建卡、同步。

为什么 Dock 里没有图标？

它默认常驻在右上角菜单栏（取景框里一个 A），设置和词库都从那里打开。想在 Dock 里也看到，打开设置 › 通用里的 Dock 里显示图标。

Intel 芯片的 Mac 能用吗？

能。同一个安装包 Apple 芯片和 Intel 都能用，需要 macOS 14 或更新。

    隐私政策

    我们会给前 100 位用户免费额度，所以需要统计有多少人在用。统计是匿名的。
    GetNewWord 把词库存在你的电脑上。查词时只有框住的那一块和它所在的句子发给你选的 AI。不需要账号；只有登录了同步的电脑，词库里的文字才会存到云端。你同意的话，应用每天发一次匿名统计，只用来数有多少人在用。我们不卖任何数据。

    我们是谁

    GetNewWord 是 SchaeferAnjon 开发和维护的开源软件（GPL-3.0-or-later），源码在 GitHub。这份政策说明应用和本网站会把哪些数据发到哪里。有问题请写信到 infoschaeferanjon@gmail.com。

    截图和文字

    只有你取词时（按快捷键、点悬浮按钮或菜单栏里的取词）才截屏，而且只留词附近那一块。截图和单词一起存在你电脑上；用了 Anki 的话也会放进卡片。

    AI 服务

    自带 Key：框住的那一块（截图，或在你电脑上先认出的文字）和它所在的句子，从你的电脑直接发给你选的服务商，受该服务商的隐私政策约束，我们看不到。会员：同样的内容经我们的服务器（api.us-cloud.uk）转给 DeepSeek，受 DeepSeek 的隐私政策约束；我们的服务器每次查词只记时间、请求次数和 token 数，用来计次数和防滥用，不保存你查的内容和截图。

    设备标识

    只在用会员时。第一次用会员时，应用把这台 Mac 向我们的服务器（api.us-cloud.uk）注册一次，用来发免费试用、记你还剩几次。发过去的是设备标识：这台 Mac 的硬件编号（IOPlatformUUID）加上 getnewword 这个词做的 SHA-256 哈希，不是硬件编号本身，别的软件算不出同一个值；服务器只存它再加盐的哈希，另外记下系统类型（macOS）、你的网段（IP 地址的前三段，用来限制同一个网络每天领试用的台数，不存完整的 IP 地址），以及注册和最后一次使用的时间。服务器发给这台 Mac 一个随机的设备令牌，存在你 Mac 的钥匙串里。之后每次查词，服务器记下时间、请求次数和 token 数，不记内容。同一台 Mac 重装应用还是同一台，不会再发一次试用。同一台 Mac 再注册一次（比如令牌丢了）时，服务器记下时间：24 小时里只能重新注册几次，免得一台 Mac 的标识被拿去多台电脑共用一个会员。服务器还记下这台领没领到免费试用，没领到的原因。用自带 Key 时不注册，也不发设备标识。想删除服务器上这台 Mac 的记录，写信到 infoschaeferanjon@gmail.com。

    购买与授权码

    付款由 Stripe 处理：刷卡、Apple Pay；人民币一次买时还能用微信支付。卡号和付款账户只在 Stripe 那里，我们看不到。Stripe 告诉我们：你填的邮箱、金额和币种、买的是月付、年付还是一次买、订阅的状态（续费、取消、退款）和 Stripe 的客户编号。我们把这些和你的授权码记在一起，用来开通和停止会员、处理退款，并按税务和记账的要求保存。授权码（GW- 开头）显示在付款页和应用里，在另一台电脑上输入它也能用（最多 2 台）。管理订阅（取消、换卡、看发票）在 Stripe 的客户门户里进行：从应用里打开，或者用登录链接，填付款时的邮箱。会员登录了同步账号的话，我们的服务器还会记下这个授权码对应哪个同步账号（Supabase 的用户编号和邮箱），并告诉 Supabase 这个账号的同步开到哪天（只有用户编号和到期日期）。

    匿名使用统计

    从 1.2.0 起，你同意以后，应用每天向我们的服务器（api.us-cloud.uk）发一次匿名统计，只有：一个随机编号（装软件时随机生成，不是硬件编号）、版本号、系统和芯片类型、用会员还是自带 Key、界面语言。不含你查的词、词库、截图、Key、名字或邮箱，统计里也不存 IP 地址。用来数每天有多少人在用：我们会给前 100 位用户免费额度，所以需要知道人数。没同意就什么都不发。新装的在欢迎引导里问，从旧版升级的第一次打开主窗口时问；之后在应用的 设置 › 更新与关于 › 匿名使用统计 里随时打开或关掉。

    发音

    朗读时，应用向这几处要这个词的音频：有道词典的公开发音接口、维基共享资源（Wikimedia Commons）里的真人录音、Google 翻译的朗读接口，发过去的只有这个词或短语。都没有时，用 Mac 自带的语音在本机朗读。下载过的发音存在你电脑上，同一个词不再联网取。

    账号与同步

    会员功能。想让几台 Mac 用同一个词库时，会员在设置 › 账号与同步里用 Google 账号登录。登录和同步用的是 Supabase（美国公司）的登录和数据库服务：它保存 Google 给的账号信息（邮箱和名字），以及你词库里的文字：单词、释义、原句和译文、分类、知识片段。发音和截图文件不同步。登录以后，应用把这次登录交给我们的服务器一次，服务器向 Supabase 确认是哪个账号，把它和你的授权码记在一起，并告诉 Supabase 这个账号的同步开到哪天。会员到期就不再同步，云端的词不删，续上以后接着同步。登录以后，应用在你登录时报一次登录，之后每天第一次打开时报一次打开；这两个事件里只有产品名和事件名，记在你的账户下，不是匿名的，用来知道有多少人在用。想删除服务器上的账户和数据，用登录的邮箱写信到 infoschaeferanjon@gmail.com。

    2. 在右上角菜单栏找到它取景框里一个 A；想在 Dock 里也看到，设置里能打开。
    3. 给一次屏幕录制权限欢迎页会带你做：把图标拖进系统设置的列表，再重开一次应用。
